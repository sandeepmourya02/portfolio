How I work

Start from the data

The unclaimed-payout module began as an analysis. Matching bank receipts against agent payouts showed which cases were stuck in suspense.

Replace the manual step

Orphaned agents used to be reassigned by hand whenever an RM left. Agent Flash turned that into a queue RMs pick from by location, profession and team.

Let the system follow up

A ticket with no response for 7 days escalates on its own, and an agent whose listing expires gets a WhatsApp check-in without anyone sending it.

American Express Decision Science Challenge

June to July 2024

Predicting player performance from time-series data, with explanations a coach could act on.

  • LightGBM
  • Hidden Markov models
  • SHAP
  • scikit-learn

  1. Features

    Rolling statistics, HMM state probabilities and player embeddings built from the time series.

  2. Model

    LightGBM ensembled with HMM outputs, trained with stratified cross-validation.

  3. Calibration

    Isotonic calibration so predicted probabilities can be taken at face value.

  4. Explanation

    SHAP surfaced recent form, positional metrics and injury history as key drivers for coaching decisions.
